# PROMPTS.md — generation prompts used in this film

**None.** No image, video, music or voice-cloning model was prompted for this film.

- Narration: Kokoro-82M text-to-speech (local, `am_onyx`), reading the narration text in `beat_sheet.json`, which
  follows `pitch/PROJECT-BRIEF.md` (Tharun's seven answers) in Tharun's first person.
- Pictures: real Movie Maker frames of the game at tag `a7`, real test output, real files, Remotion's
  `GodotDevWorkbench` code view, and drawings made in code by `_tools/make_media.py` (labelled CONSTRUCTED where they
  show something that does not exist yet).
- The one sprite placed in a drawing (Bolt's idle pose, B01) is the A2 game art (SDXL-Turbo, prompts in the
  repository's `ASSET-LOG.md`); no new art was generated.

The session prompt that built the film is in `BUILD-PROMPT.md`.
