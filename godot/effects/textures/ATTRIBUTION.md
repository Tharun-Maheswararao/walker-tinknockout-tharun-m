# Texture credits — godot/effects/textures/ (Assignment 6)

Both textures are **written by code** in this repository. No texture was downloaded or generated by a model, and no source image was used. The scripts are their provenance; rerun them to reproduce the files exactly.

| File | Size | Written by | How |
|---|---|---|---|
| `shard_8.png` | 8 × 8 | `godot/tools/generate_shard_texture.gd` (Claude, 2026-11-08) | an irregular four-sided shard: light tin inside, a 1 px dark rim, transparent outside (CHANGE-BRIEF A.3a) |
| `steam_32.png` | 32 × 32 | `godot/tools/generate_steam_texture.gd` (Claude, 2026-11-08) | a soft puff: light grey centre, a darker ring toward the edge, alpha falling to 0 at the edge (B.3); the ring and fade shapes are Claude's reading of the brief |

To regenerate them (then reimport):
```bash
godot --headless --path godot --script res://tools/generate_shard_texture.gd
```
```bash
godot --headless --path godot --script res://tools/generate_steam_texture.gd
```
```bash
godot --headless --path godot --import
```
